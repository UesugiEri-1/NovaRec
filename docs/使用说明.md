# NovaRec 使用说明（Windows 桌面录屏）

版本：1.0.0 ｜ 平台：Windows 10/11 x64 ｜ 最后更新：2026-10-31

NovaRec 是一款基于 Electron + Chromium 桌面采集（Desktop Capture / DXGI Duplication）+ ffmpeg 的 Windows 录屏工具，支持**屏幕 / 区域 / 窗口**三种录制模式，可同时录制系统声音与麦克风，支持暂停继续、倒计时与素材库管理。

---

## 一、功能一览

- 三种模式：整屏录制、矩形区域录制、单个应用窗口录制
- 输出格式：MP4（H.264 + AAC，兼容性最好）或 WebM（VP9 + Opus，体积更小）
- 音频：系统声音（默认播放设备 loopback）+ 麦克风（可分别开关，可同时录制并在采集端混音）
- 录制控制：倒计时（关闭 / 3 秒 / 5 秒）、暂停 / 继续、全局快捷键 F9（停止）、F10（暂停/继续）
- 界面：无边框浅色中文界面，白底 + 单一绿色强调色（类似杀毒软件的清爽风格），顶部标签栏切换录制/素材库/设置，底部状态栏显示版本与「打开保存目录」；圆角克制（容器方角、控件 2px）；托盘常驻，关闭主窗口只隐藏到托盘
- 图标：绿色 squircle 底 + 白色准星标记（四段弧环 + 四向刻度 + 中心点），与界面配色一致；托盘为白色单色线稿，录制中切换为红点状态
- 素材库：自动收录录制结果（缩略图、分辨率、时长、大小），支持播放、定位文件、删除
- 单实例运行：同一数据目录只允许一个实例，重复启动会激活已有窗口

---

## 二、系统要求

- 操作系统：Windows 10 64 位（本机在 Windows 10 交互桌面实测）或 Windows 11 x64
- 显卡：支持 Windows 桌面复制（DXGI Desktop Duplication）的显卡（本机 AMD Radeon Vega 6 实测通过；无独显的核显一般也支持）
- 显示器：任意分辨率；支持系统缩放 100%–200%（本机 125% 缩放、物理 1920×1080 实测通过）
- 内存：建议 4 GB 以上
- 磁盘：1080p30 高清约 6–8 Mbps，每分钟约 45–60 MB；WebM 通常更小
- 打包版已内置 Electron 45（Chromium 156）运行时与 ffmpeg.exe，**无需安装 Node.js / ffmpeg**

## 三、启动方式

### 3.1 安装包版（Setup.exe，推荐普通用户）

交付文件 `NovaRec-Setup-1.0.0-x64.exe`（约 122 MB，NSIS 安装包，已做代码签名，签名说明见第十二节）。

安装步骤：

1. 双击 `NovaRec-Setup-1.0.0-x64.exe`
2. 首屏「安装选项」保持默认的「仅为我安装」（当前用户，无需管理员），点「下一步」
3. 「选择安装位置」页可修改安装目录，点「安装」开始复制文件（约 40–60 秒）
4. 完成后可勾选「运行 NovaRec」直接启动，也可以双击桌面/开始菜单中的 NovaRec 快捷方式
5. 卸载：Windows 设置 → 应用 → 已安装的应用 → 「NovaRec 录屏」→ 卸载；或运行安装目录下的 `Uninstall NovaRec.exe`

安装包特性：

- 安装范围：默认仅当前用户（无需管理员）；首屏选择「为使用这台电脑的任何人安装」会请求 UAC 提权
- 默认安装目录：`%LOCALAPPDATA%\Programs\NovaRec`（可在向导第 3 步修改）；用户数据保存在安装目录下的 `NovaRecData`
- 默认创建桌面快捷方式与开始菜单项（运行卸载程序时会一并清理）
- 安装包与便携版功能完全一致，只是安装位置与快捷方式管理方式不同

静默安装（批处理/部署用）：

    NovaRec-Setup-1.0.0-x64.exe /S /currentuser /D=D:\NovaRec

> 注意：`/D=<绝对安装路径>` **必须是最后一个参数且不能加引号**。部分安全软件（HIPS）会拦截安装程序写入系统盘，表现为静默安装返回成功但 0 个文件落地；遇到这种情况请把安装位置改到非系统盘，或直接使用下一节的便携版。

### 3.2 便携版（zip，免安装，推荐在本机使用）

1. 解压交付包：NovaRec-1.0.0-win32-x64.zip
2. 进入解压出的 NovaRec-win32-x64 文件夹，双击 NovaRec.exe
3. 首次运行若出现 Windows SmartScreen / 杀毒软件提示，选择「更多信息 → 仍要运行」或将文件加入信任（程序已带自签名证书，但该证书不在 Windows 受信任根证书列表内，因此仍会提示"未知发布者"，属正常现象，见第十二节）
4. 数据目录：与 exe 同级的 NovaRecData 文件夹（保存设置与素材库 library.json）。这是便携式布局，移动程序时请把整个文件夹一起移动

命令行启动（可选；把「解压目录」替换成实际解压位置）：

bash：

    cd /d/解压目录/NovaRec-win32-x64
    ./NovaRec.exe --no-sandbox

PowerShell：

    cd D:\解压目录\NovaRec-win32-x64
    .\NovaRec.exe --no-sandbox

> 说明：部分机器/受限环境下 Electron 需要 --no-sandbox 才能启动（受限环境验证所需）；普通机器直接双击即可。

### 3.3 开发版（源码运行）

前提：已按 [构建文档](build.md) 完成依赖安装（Node.js 20+、`npm ci`、补装 Electron 二进制）。

bash（Git Bash / MSYS）：

    cd novarec
    npm start

PowerShell：

    cd novarec
    npm start

注意事项：

- 若环境变量 ELECTRON_RUN_AS_NODE 存在，Electron 会以纯 Node 模式运行、不显示窗口，启动前必须清除（Git Bash：`unset ELECTRON_RUN_AS_NODE`；PowerShell：`$env:ELECTRON_RUN_AS_NODE = $null`）
- 部分受限环境（虚拟机 / 企业策略）必须加 --no-sandbox 才能启动，用 `npm run start:nosandbox` 或设置 `NOVAREC_NO_SANDBOX=1`
- 开发版 userData 位于项目内 .data 目录（项目根/.data），素材库为 .data/library.json；删除 .data 可恢复默认设置
- 单实例锁按 userData 生效，同一数据目录只能跑一个实例

## 四、界面与三种录制模式

主界面顶部是标签栏：录制 / 素材库 / 设置，右侧显示 F9、F10 快捷键提示；底部是状态栏（版本号、打开保存目录按钮）。录制页上方是三种连体模式卡片（屏幕 / 区域 / 窗口），下方分为左右两列：左列是来源选择（屏幕缩略图或窗口列表）与「输出」区块（性能模式、保存位置），右列是「声音」与「画面」参数面板（系统声音、麦克风、帧率、画质、格式、倒计时）；页面底部是固定的操作条，右侧为绿色「开始录制」按钮。

### 4.1 屏幕录制（整屏）

1. 打开「录制」页，模式选「屏幕录制」（默认）
2. 在「选择屏幕」缩略图列表中点击要录制的显示器（多显示器时每块屏一张缩略图）
3. 设置参数：系统声音、麦克风（含设备选择）、帧率、画质、格式、倒计时、性能模式（见第十四节）；「保存位置」显示当前输出目录，可点「打开文件夹」
4. 点击「开始录制」（或托盘菜单「开始录制」），倒计时窗显示「即将开始录制」，倒计时结束自动开始（操作条此时切换为计时 + 暂停/停止按钮）
5. 录制中：开启「录制时隐藏主窗口」时主窗口自动隐藏，托盘图标切换为录制态；按 F10 暂停/继续，按 F9 停止（也可用主界面/托盘按钮）
6. 停止后自动处理视频（封装/转码 + 生成封面），提示「录制完成：文件名」，并自动打开素材库页

输出：原生画质下分辨率等于该显示器的物理分辨率（本机 1920×1080）；开启性能模式后采集与输出上限为 1280×720 / 30 fps（见第十四节）。

### 4.2 区域录制（矩形框选）

1. 模式选「区域录制」
2. 点击「选择区域」：屏幕变暗并出现框选覆盖层，按住鼠标左键拖动画出矩形，松开鼠标完成；按 Esc 取消；已选区域可点「清除」重选
3. 框选完成后显示区域尺寸，按屏幕模式的方式设置参数并开始录制

尺寸说明：框选坐标是 DIP（逻辑像素），视频按物理像素输出：**视频尺寸 = 区域 DIP 尺寸 × 系统缩放比例**（本机 125% 缩放下，800×600 的区域输出 1000×750 视频；宽高会取偶数）。

限制：区域不能跨显示器；框选范围超出所选显示器时会被裁剪（以区域中心点所在显示器为准）。

### 4.3 窗口录制（单个应用窗口）

1. 模式选「选择窗口」
2. 在窗口列表中点击目标窗口（列表为系统当前窗口的缩略图，支持刷新与搜索）
3. 开始录制

行为与限制：

- 只采集所选窗口的画面，窗口移动/缩放时画面跟随
- 部分窗口无法被桌面复制直接抓取（UWP 应用、部分硬件加速/受保护内容、DirectComposition 合成窗口等）。此时程序会**自动降级为区域裁剪**：录制该窗口所在的屏幕区域，可能录到窗口后面/周围的其他内容（状态会标记降级 fallback）
- 录制过程中窗口关闭，本次录制会失败/中断并提示错误
- 需要纯净画面时，建议改用「区域录制」或先把目标窗口最大化

## 五、快捷键与托盘

- F9：停止录制（倒计时阶段按 F9 可取消本次录制）
- F10：暂停 / 继续（暂停时间不计入视频时长）
- 全局快捷键仅在倒计时/录制/暂停期间注册，未录制时不会占用系统的 F9/F10
- 托盘菜单：显示 NovaRec 主界面 / 开始录制（固定为屏幕模式，沿用当前设置）/ 暂停（F10）/ 停止（F9）/ 打开保存目录 / 退出 NovaRec
- 关闭主窗口（右上角 ×）只是隐藏到托盘；要真正退出程序请用托盘菜单「退出 NovaRec」

## 六、设置页说明

| 设置项 | 说明 |
| --- | --- |
| 保存位置 | 视频输出目录，默认「视频\NovaRec」（C:\Users\<用户名>\Videos\NovaRec）；可更改、可打开文件夹 |
| 默认格式 | MP4（H.264 Baseline + AAC，兼容性最好）/ WebM（VP9 + Opus，体积更小，部分播放器不支持） |
| 画质 | 标准 / 高清 / 超清 三档（按分辨率×帧率估算码率：标准约 0.08、高清 0.15、超清 0.25 系数，码率限制在 1.5–16 Mbps） |
| 帧率 | 30 fps / 60 fps（60 fps 更流畅，文件更大、CPU 占用更高） |
| 性能模式 | 自动 / 开启 / 关闭，默认「自动」：低配电脑（≤4 核或 ≤8 GB 内存）自动启用 720p·30fps、画质封顶「标准」、码率约 4.5 Mbps，并关闭界面装饰动画；开启后帧率/画质会自动封顶（详见第十四节） |
| 倒计时 | 关闭 / 3 秒 / 5 秒 |
| 录制时隐藏主窗口 | 默认开启；开始录制时自动隐藏主窗口，避免把 NovaRec 自己录进画面 |
| 鼠标指针 | 程序默认包含鼠标光标（settings.showCursor 默认 true），当前界面未提供开关（见「已知限制」） |

## 七、素材库

- 每次录制成功后自动加入素材库：封面缩略图、文件名、分辨率、时长、文件大小、录制时间
- 操作按钮：
  - 播放：用系统默认播放器打开视频
  - 在文件夹中显示：在资源管理器中定位该文件
  - 删除：二次确认后把视频文件移入系统回收站（可从回收站恢复）
- 记录保存在 userData 目录的 library.json；若手动移动/删除了视频文件，素材库中的播放/定位会失败，可删除该条目

## 八、输出文件与目录

- 默认输出目录：「视频\NovaRec」（即 C:\Users\<用户名>\Videos\NovaRec）
- 文件名格式：NovaRec_年月日_时分秒.mp4 / .webm，例如 NovaRec_20261031_190259.mp4
- 同时生成同名 .jpg 封面（素材库缩略图）
- MP4：采集即 MP4 时优先用 ffmpeg -c copy 快速封装（+faststart）；封装失败会自动转码（libx264 veryfast CRF20 + AAC 160k），此时保存耗时会明显变长
- WebM：libvpx-vp9 CRF32 + Opus 128k 转码，保存较慢
- 打包版数据目录：exe 同级 NovaRecData（设置、素材库、临时录制文件）

## 九、从源码打包（开发/交付）

命令（在项目根目录执行）：

    node scripts\package.mjs

scripts/package.mjs 的实现要点：

- 使用 @electron/packager 20.3.0 的 API（不是 CLI）：dir=项目根、out 由 --out 指定（默认 artifacts/dist；本项目实际交付时先输出到 artifacts/dist2，见下方流程）、overwrite=true、platform=win32、arch=x64、name=NovaRec、appVersion 取 package.json（1.0.0）、icon=assets/icon.ico
- asar 打包，并对 **/node_modules/@ffmpeg-installer/** 解包（ffmpeg.exe 必须位于 resources/app.asar.unpacked 下才能被调用）
- ignore 排除：artifacts/、.data*、.electron-cache/、.etmp/、docs/、scripts/、.git；prune 裁剪 devDependencies（保留生产依赖与 optionalDependencies）
- 复用本地 Electron zip（项目 .electron-cache），不联网下载；不执行 npm install / rebuild
- 打包后自动校验：NovaRec.exe 存在、resources/app.asar 存在且含 src/main/main.js 与 src/renderer/index.html、app.asar.unpacked 内 ffmpeg.exe 存在且大于 10 MB；报告写入 artifacts/build/packaging-report.json
- 参数：--out=DIR 指定输出目录（如 --out=artifacts/dist2）；--zip 打包校验通过后自动生成交付 zip 并用 tar -t 校验条目（NovaRec.exe、resources/app.asar、ffmpeg.exe、使用说明.md），同时把 docs/使用说明.md 复制进产物根
- 只校验已有产物（不重新打包）：node scripts\package.mjs --verify-only（可再加 --zip 重打交付 zip）

本项目的实际打包交付流程（三步）：

1. node scripts\package.mjs --out=artifacts/dist2  —— 先打包到干净目录
2. 把 artifacts/dist2/NovaRec-win32-x64 下的全部文件装配到最终目录 artifacts/dist/NovaRec-win32-x64；其中 resources/app.asar 必须用「原地覆盖写」方式复制（目标目录里已有的 app.asar 可能被其他进程占用，直接删除整个目录会 EBUSY / Permission denied）
3. node scripts\package.mjs --verify-only --zip  —— 校验最终产物并重打 zip（这一步还会把最新版使用说明同步进 dist 与 zip）

压缩交付包（两种方式，任选其一）：

    node scripts\package.mjs --verify-only --zip

或手工打包：

    %SystemRoot%\System32\tar.exe -a -c -f artifacts\NovaRec-1.0.0-win32-x64.zip -C artifacts\dist NovaRec-win32-x64

> 注意：Git Bash 自带的 GNU tar 会把盘符 `D:` 误当成远程主机（报 "Cannot connect to D: resolve failed"），必须用 Windows 自带的 `%SystemRoot%\System32\tar.exe`（bsdtar）。zip 内必须包含 NovaRec-win32-x64/NovaRec.exe、resources/app.asar、resources/app.asar.unpacked/node_modules/@ffmpeg-installer/win32-x64/ffmpeg.exe 与中文使用说明.md。

产物目录：artifacts/dist/NovaRec-win32-x64/（本机实测 85 个文件、约 420 MiB；交付 zip 约 173 MiB）。

## 十、常见问题（FAQ）

**1. 打开程序后黑屏 / 白屏 / 窗口一片空白？**

- 首次启动需要 1–3 秒初始化（GPU/界面），稍等片刻
- 开发版必须确认已清除 ELECTRON_RUN_AS_NODE 并加 --no-sandbox
- 若界面仍空白，检查显卡驱动是否过旧；可尝试设置环境变量 NOVAREC_DISABLE_GPU=1（或命令行加 --disable-gpu）后重启
- 查看日志或终端输出中的错误信息

**2. 录出来的视频没有系统声音？**

- 系统声音录的是 Windows **默认播放设备**的输出。若该设备被静音或音量为 0，录到的就是静音（实测静音端点会得到约 -91 dB 的静音音轨）
- 录制前检查任务栏音量图标未被静音、音量不为 0；用其他播放器确认声音能正常外放
- 只支持默认输出设备：切换 HDMI/蓝牙/耳机后需要重新开始录制
- 若目标应用使用独占模式或 DRM 内容，可能无法被采集

**3. 窗口录制失败 / 画面不是想要的窗口？**

- 部分窗口（UWP、硬件加速、受保护内容、DirectComposition 窗口）无法被桌面复制直接抓取，程序会自动降级为「区域裁剪」，会把窗口后面的画面一起录进去
- 此时建议：最大化目标窗口后重试，或改用「区域录制」
- 窗口在录制中关闭也会导致本次录制失败

**4. 杀毒软件 / SmartScreen 提示风险？**

- 交付的 exe 已用自签名证书签名（SHA-256 + DigiCert 时间戳），但证书不在 Windows 受信任根证书列表内，SmartScreen 仍可能提示「未知发布者」，属正常现象；选择「仍要运行」或将文件加入杀软白名单即可（信任证书的方法见第十二节）
- 本机出现过火绒 HIPS 拦截安装程序写入 C: 盘的情况：安装包装到 C: 盘会失败，请改装到 D: 盘或使用便携版
- 请不要把压缩包当作加密文件，它只是普通 zip

**5. 125% 缩放下录出来的尺寸和框选的不一样？**

- 框选使用逻辑像素（DIP），视频按物理像素输出，因此 125% 缩放下 800×600 的框会得到 1000×750 的视频
- 这是有意行为：保证录制清晰度不因系统缩放而损失
- 屏幕录制固定输出显示器物理分辨率（如 1920×1080）

**6. 录制文件太大 / 保存太慢？**

- 降低画质档位与帧率（30 fps），或选择 WebM 格式
- 选择 WebM 或需要转码的 MP4 时，停止后可能等待较久（进度提示「正在保存视频…」），请耐心等待
- 确保输出目录所在磁盘有足够空间

**7. WebM 视频在部分播放器里打不开？**

- 请用支持 VP9 的播放器（Chrome/Edge、VLC、PotPlayer 等）
- 需要最大兼容性请选 MP4

**8. 停止后一直显示「正在保存视频…」或提示处理失败？**

- 大分辨率/长视频转码耗时较长属正常
- 若失败，检查：磁盘空间、输出目录是否可写、杀毒软件是否拦截 ffmpeg.exe、视频临时文件是否被杀软隔离

**9. F9 / F10 没反应？**

- 全局快捷键只在倒计时/录制/暂停期间注册，未录制时不生效
- 部分应用会占用 F9/F10，可改用主界面按钮或托盘菜单控制

**10. 素材库为空 / 一直显示「加载中」？**

- 素材库只显示录制成功的视频；若之前录制失败则不会出现
- 若刚启动时显示加载中，稍等；持续异常可删除 userData 下 library.json 后重启（素材库记录重建，不影响视频文件）
- 若视频文件被手动移动/删除，条目会失效

**11. 双击 exe 没反应 / 提示已有实例？**

- 同一数据目录只允许一个 NovaRec 实例；重复启动会激活已运行的主窗口（可能在托盘里）
- 检查托盘图标，或任务管理器查看是否已有 NovaRec 进程残留

**12. 开发版启动报错（userData 锁 / 单实例）？**

- 确认没有残留的 electron.exe 进程占用同一 userData
- 项目内 .data 目录可删除后重建（仅测试用，会清空设置与素材库记录）
- 启动命令必须带 --no-sandbox 并清除 ELECTRON_RUN_AS_NODE

## 十一、已知限制

- 系统声音仅采集默认播放设备；端点静音时录到静音。不支持应用级分流、不支持多输出设备混音
- 系统声音与麦克风同时开启时在采集端实时混音，输出单音轨，无法后期分离
- 窗口录制依赖桌面复制（Desktop Capture）。部分窗口（受保护窗口或记事本等 Chromium 无法直接采集的窗口）无法直接采集时，NovaRec 会自动切换为「激活窗口 + 屏幕裁剪该窗口区域」的方式继续录制：此时请勿让其他窗口遮挡被录窗口、也尽量不要移动它，否则会录到遮挡物/背景（这是平台限制，不是程序缺陷）
- 区域录制按物理像素输出，且不支持跨显示器框选
- 鼠标指针始终录入，界面暂未提供开关
- 性能模式开启时采集分辨率上限 1280×720：区域录制从整屏 720p 源裁剪，区域越小输出像素越少（本机实测 800×600 DIP 区域输出 668×500）；窗口录制最宽 1280、最高 720。需要原始分辨率时请把性能模式改为「关闭」
- 画质/帧率仅提供预设档位（标准/高清/超清；30/60 fps），未提供自定义码率
- 无摄像头画中画、无剪辑/压缩工具、无直播推流、无计划录制
- 程序已签名（自签名证书，非商业 CA 证书）：Windows 未信任该证书时仍显示「未知发布者」，且无法抑制 SmartScreen 警告；对外正式分发建议购买商业代码签名证书后重新签名
- 本机环境（火绒 HIPS）会拦截安装程序写入 C: 盘：安装到 C: 盘会失败，请装到 D: 盘或直接用便携版（详见第十二节）
- zip 未加密
- 打包版为便携式布局，数据保存在 exe 同级 NovaRecData，移动或升级时请整体替换并保留该目录
- 托盘「开始录制」固定为屏幕录制模式（沿用当前设置）

## 十二、代码签名与信任说明

### 12.1 已做的签名

- 便携版主程序 `NovaRec.exe` 与安装包 `NovaRec-Setup-1.0.0-x64.exe` 均已做 Authenticode 代码签名
- 算法：SHA-256；时间戳服务器：`http://timestamp.digicert.com`（DigiCert SHA256 RSA4096 Timestamp Responder 2026）
- 证书：自签名代码签名证书（Subject：`CN=NovaRec, O=NovaRec, OU=Desktop, C=CN`，有效期 2026-10-31 → 2031-10-31，保存在本机当前用户证书库 `Cert:\CurrentUser\My`；证书文件：`.certs\NovaRec-CodeSigning.cer`）
- 签名结果：文件带有有效的 Authenticode 签名与时间戳（即使证书过期，签名时间仍可验证）

### 12.2 为什么 Windows 还提示"未知发布者"

自签名证书的根不在 Windows 受信任根证书列表中，因此 `Get-AuthenticodeSignature` 状态为 `UnknownError`，提示"已处理证书链，但终止于不受信任的根证书"。这不是签名失败，而是缺少证书信任链。要消除提示，需要：

1. 在**目标电脑**上把 `.certs\NovaRec-CodeSigning.cer` 安装到「受信任的根证书颁发机构」（会弹出 Windows 安全警告，需要手动点「是」）
2. 或购买商业 CA 代码签名证书重新签名（正式对外分发推荐；自签名证书也无法避免 SmartScreen 提示）

### 12.3 本机一键信任（可选）

在项目根目录打开 PowerShell 执行：

    powershell -NoProfile -ExecutionPolicy Bypass -File scripts\trust-cert.ps1 -Paths artifacts\NovaRec-Setup-1.0.0-x64.exe

脚本会把 `.certs\NovaRec-CodeSigning.cer` 装入当前用户的「受信任的根证书颁发机构」与「受信任的发布者」，并在弹出系统安全警告时等待你点「是」，随后验证签名状态。撤销信任：

    powershell -NoProfile -ExecutionPolicy Bypass -File scripts\untrust-cert.ps1

验证签名（不改系统状态）：

    powershell -NoProfile -ExecutionPolicy Bypass -File scripts\verify-sign.ps1 -Paths artifacts\NovaRec-Setup-1.0.0-x64.exe

> 注意：信任自签名证书只在**本机/受控环境**有意义；分发给他人时对方仍需自行决定是否信任。正式发布请换用商业 CA 证书。

## 十四、性能优化与老设备建议

### 14.1 这一版做了哪些优化

- **性能模式**（自动 / 开启 / 关闭）：在采集入口直接请求 1280×720、30 fps、码率上限 4.5 Mbps，画质档位封顶「标准」，WebM 优先 VP8（老 CPU 编码更省），音频 96 kbps，分片 2 s（写盘次数减半）；降采样在 Chromium 采集层完成，不需要额外的 canvas 缩放，几乎不增加 CPU
- **自动判定**：CPU ≤4 核或内存 ≤8 GB 视为低配，自动开启性能模式（本机 4 核 / 13.9 GB → 自动开启）；可在设置中强制「开启」或「关闭」
- **界面精简（perf-lite）**：性能模式启用时关闭界面的装饰动画与过渡（新版界面已无毛玻璃与渐变高光，perf-lite 主要关闭动画），降低低端 GPU 的合成开销
- **收尾校验提速**：ffmpeg 校验由「全片解码」改为「仅解复用」，1080p 文件从约 4.9 s 降到约 0.5 s；ffmpeg 进程降到低于正常优先级，收尾时更不抢占前台
- **阻止显示器休眠**：录制期间持有 powerSaveBlocker（阻止显示器休眠），长时间录制不会因息屏中断
- **隐藏采集窗口回收**：停止录制后空闲 180 s 自动销毁隐藏的采集窗口，录制结束即释放这部分内存
- **主进程减负**：主窗口隐藏时不推送录制状态（缓存，重新显示时补发）；托盘图标/菜单按状态去重，不再每次全量刷新；屏幕/窗口源列表 800 ms 短缓存；封面图按「路径 + 修改时间 + 大小」缓存
- **渲染层减负**：录制计时从每 500 ms 刷新改为每秒刷新一次（时间显示本来就是秒级）

### 14.2 怎么选

| 你的情况 | 建议 |
| --- | --- |
| 不确定 / 普通办公电脑 / 老笔记本 | 保持默认「自动」 |
| 录制时明显卡顿、风扇狂转、录像掉帧 | 手动改为「开启」 |
| 要录 1080p / 60 fps / 超清，或需要小区域的高清画面 | 手动改为「关闭」 |
| 只录操作演示、教程、会议记录 | 「开启」即可，720p 完全够用，文件也更小 |

> 注意：性能模式是用「降低采集分辨率」换性能，不是后期压缩。录完之后不会自动转码，画质上限在录制时就已确定。

### 14.3 在哪里设置

- 录制页右侧参数面板 →「性能」分组 → 性能模式：自动 / 开启 / 关闭，下方显示当前生效状态（如「已启用 · 720p · 30fps · 约 4.5 Mbps」）
- 设置页 →「性能」卡片 → 性能模式与当前状态（含硬件信息：处理器核数 / 内存）
- 关于页 → 显示本机硬件与性能模式状态
